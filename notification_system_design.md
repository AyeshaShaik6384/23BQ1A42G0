# Stage 2

## Features

- Notification Display
- Filter by Type
- Top N Notifications
- Read / Unread Toggle
- Logging Middleware Integration

## State Management

React useState is used to maintain:

- Notification List
- Filter Selection
- Top N Value
- Read Status

## User Interaction

Users can:

- View notifications
- Filter notifications
- Limit displayed notifications
- Mark notifications as read/unread
